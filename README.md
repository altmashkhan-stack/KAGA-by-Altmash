## 📖 About the Project

**KAGA** (also known as *Kage no Michi* —, "The Shadow Path") is a cinematic, scroll-driven **3D web experience** built by **Altmash**, taking visitors on a contemplative, five-chapter night walk through a fictional Kyoto mountain temple sanctuary.

Rendered live in the browser using **Three.js / WebGL**, the site blends atmospheric storytelling, Japanese garden aesthetics, bilingual (English + Japanese) narrative design, and smooth scroll-based 3D navigation to create a meditative digital art piece — not just a website, but an *experience*.

> *"A 92-minute virtual walk through burned-cedar gates, moonlit gardens, and sacred craft — where every scroll reveals the unseen."*

---

## 🎴 The Experience — Five Chapters

| Chapter | Title | Description |
|--------|--------|--------------|
| **00** | **The Hidden Gate** | Opening threshold — introduces the walk, four core paths: Thresholds, Still Gardens, Sacred Craft, Night Rituals |
| **01** | **The Sanmon ** | A burned-cedar mountain gate and lit worship hall beneath a vermilion moon — hall dated 1611 |
| **02** | **Still Gardens ** | Three garden zones — Approac , Lanterns , Moonwater |
| **03** | **Sacred Craft ** | Five guided walks: The Hidden Gate, Borrowed Scenery, Charred Cypress, Lantern Light, The Vermilion Moon |
| **04** | **Afterlight** | Closing reflection, inviting visitors to re-walk the path |

## ✨ Key Features & Integrations

- 🌐 **Live 3D Rendered Environment** — Built with **Three.js**, rendered directly in-browser via **WebGL**, no plugins required
- 🖱️ **Scroll-Driven Navigation** — Each scroll motion advances the story, like turning a page in a physical journey
- ⏳ **Custom Preloader** — "Raising the mountain temple" progress loader (0–100%) for a cinematic entry
- 🎋 **Bilingual Storytelling** — English narrative paired with authentic Japanese (Kanji) labels: 
- 🏮 **Atmospheric Visual Design** — Charred-wood blacks, warm lantern amber, vermilion red accents, and misty garden greens
- 🖼️ **Curated Imagery** — WebP-optimized photography: temple walls, pine, sakura branches, maple leaves, stone lanterns, basalt stones, shrine ruins
- 🔤 **Custom Typography** — Set in **Onest**, a clean modern geometric typeface
- 🧭 **Dual Navigation System** — Top navbar (Temples, Gardens, Rituals, Afterlight) + detailed footer map (Chapters / Practice / Elsewhere)
- 📱 **Fully Responsive** — Seamless 3D/scroll experience across desktop and mobile
- 🎯 **Slow, Intentional Pacing** — UX designed around stillness and contemplation rather than speed

## ⚙️ Getting Started

### Prerequisites
A modern browser with WebGL support (Chrome, Edge, Firefox, Safari — latest versions).

### Run Locally

```bash
# Clone the repository
git clone https://github.com/altmashkhan-stack/KAGA-by-Altmash.git

# Navigate into the project folder
cd KAGA-by-Altmash

# Serve locally (3D/WebGL assets require a local server, not file:// )
npx serve .
```

Then open `http://localhost:3000` in your browser.
